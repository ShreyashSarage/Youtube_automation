# API Mastery Track — APIs · Scaling · Rust APIs · IoT Security

**Deadline:** 1 January 2027 · **Start:** 19 November 2026 (≈ 6 weeks / 43 days)
**Split:** 20% theory, 80% hands-on · **Format:** one lesson at a time, quiz gate before moving on.

| File | What it is |
|---|---|
| [ROADMAP.md](ROADMAP.md) | Full plan: modules, order, daily schedule, projects |
| [PROGRESS.md](PROGRESS.md) | Your tracker: quiz scores, knowledge gaps, project status |
| [lessons/](lessons/) | One lesson per file. Unlocked as you pass quizzes |
| [labs/](labs/) | Your code for exercises and projects |

## How each lesson works
1. **Read** (≈15 min theory — the 20%).
2. **Do** the exercises (≈60–90 min — the 80%). Type everything; never copy-paste.
3. **Quiz gate** — reply with your answers. Score ≥ 80% → next lesson. Below → targeted review.
4. Gaps get logged in `PROGRESS.md` and recycled into later exercises.

## Daily rhythm (≈3 hours)
- 20 min: review yesterday's gaps (flashcards from PROGRESS.md)
- 30 min: new theory
- 2 h: build / break / fix
- 10 min: write 3 lines in your log: *what I built, what confused me, what I'll try tomorrow*
